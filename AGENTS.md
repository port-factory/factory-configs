# factory-port

Skills and examples for building Port software factory lines.

- To create, change or debug a factory line, use the `create-factory-line` skill (`.agents/skills/create-factory-line/SKILL.md`).
- `examples/ui-bugs-line.yaml` is a complete, working line.
- Edit skills only in `.agents/skills/`, then run `scripts/sync-skills.sh` to update `.claude/skills/` and `.cursor/skills/`.
